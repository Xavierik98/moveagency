Installation Outlook (Windows) :

1. Appuie sur Win + R, tape : %APPDATA%\Microsoft\Signatures → Entrée
2. Copie le fichier MoveAgency.htm dans ce dossier
3. Dans Outlook → Fichier → Options → Courrier → Signatures
4. Sélectionne MoveAgency pour Nouveaux messages et Réponses/Transferts
5. Clique OK — c'est fait ✅
